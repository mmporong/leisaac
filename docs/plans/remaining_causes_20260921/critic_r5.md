## 3. 리드가 지목한 세 가지

### (a) 2.2 진입 디스크 게이트 9.5 GB는 계획 자신의 원장과 정합하지 않는다

`:804-820`의 원장을 2.2 진입 여유 `F`의 함수로 다시 쓰면 이렇다. 계획의 숫자와 정확히 일치한다.

| 시점 | F 대비 누적 | 원장 값 (F = 14,417) | 8,192 MiB 가드 |
| --- | --- | --- | --- |
| split 3종 종료 | F − 5,260 | 9,157 | 통과 |
| 학습 1 종료 | F − 5,700 | 8,717 | 통과 |
| 학습 2 종료 | F − 5,978 | 8,439 | 통과 |
| **학습 3 종료 (최저점)** | **F − 6,256** | **8,161** | **미달 31 MiB** |
| S′ 종료 | F − 6,565 | 7,852 | 미달 340 MiB |

따라서 **필요한 진입 여유는 이렇다.**

| 목표 | 필요한 F | 환산 |
| --- | --- | --- |
| 학습 3건 완주 | **14,448 MiB** | 약 14.1 GiB |
| S′까지 완주 | 14,757 MiB | 약 14.4 GiB |
| 학습 3건 완주 (1,313 MiB 회수 후) | 13,135 MiB | 약 12.8 GiB |

**게이트가 9.5 GB로 설정돼 있다.** 원장의 진입 시점 값은 14,417 MiB이므로 이 게이트는
**언제나 통과한다.** 구속하지 않는 게이트다. 그리고 통과시킨 뒤에
원본 감사 15분 + 재렌더 87분 + 재감사 15분 + 변환 151분 + split 10분을 모두 소모하고 나서
학습 3에서 31 MiB 차이로 `RuntimeError`가 난다.

계획은 이 사실을 `:822-824`에서 **스스로 정확히 서술한다.** "학습 3이 진행 중 8,161 MB로
가드 아래를 스치고, S′는 시작 시점부터 가드 미만이다." 문제는 그 인식이
게이트 값으로 옮겨지지 않은 것이다. `:830-833`의 회수 규칙 3이 "그래도 부족하면 보고하고
사용자 판단을 받는다"로 되어 있어, **판단 시점이 약 4시간 뒤로 밀린다.**

**오늘 실측은 더 빠듯하다.** 방금 측정한 `/data` 여유는 **14,531 MiB**로,
계획이 적은 14,605 MiB보다 74 MiB 적다. 계획 기간의 감소 추세(16.9 → 15.9 → 14.6 → 14.5 GB)가 이어졌다.

| 항목 | 값 |
| --- | --- |
| 오늘 여유 | 14,531 MiB |
| 2.2 진입 여유 (−188) | 14,343 MiB |
| 학습 3 최저점 | 8,087 MiB |
| 8,192 MiB 가드 대비 | **−105 MiB. 미달** |

**즉 오늘 시작하면 회수 없이는 학습 3건을 끝낼 수 없다.**
`outputs/mimic_reset_fixed_76_20260921/raw`(실측 1,253 MiB, 계획 표기 1,313 MB) 회수를
승인받으면 진입 실효 여유가 15,596 MiB가 되어 학습 3 최저점 9,340 MiB, S′ 최저점 9,031 MiB로
둘 다 가드 위에서 끝난다.

**게이트를 원장에서 역산한 값으로 바꾸면 이 결정이 앞으로 당겨진다.** 4시간을 쓰기 전에
사용자에게 회수 여부를 묻게 된다. `:830`의 규칙 3을 진입 게이트로 승격하는 한 줄 변경이다.

**단위 표기도 통일해야 한다.** 게이트는 `9.5 GB`·`9 GB`로 적혀 있고 가드는 GiB다.
9.5 GB = 9,500 MB와 9.5 GiB = 9,728 MiB가 다르다. 원장이 MiB 기준이므로 게이트도 MiB로 적는 편이 안전하다.

**자기 정합성은 확인했다.** S′ 게이트(`:778` "여유가 9 GB 이상")는 S′ 시작 시점 값 8,292 MiB를
막으므로 방향이 맞다. 원장 합계도 맞다. `과제 1·2.0·2.1·3.2 −188`은
1.3의 55 + 2.0의 2 + 2.1의 60 + 3.6의 71 = 188과 정확히 일치한다.
문제는 2.2 진입 게이트 하나다.

`:830-833`의 회수 규칙은 안전하다. 규칙 2(학습 완료 직후 그 arm 데이터셋 회수)가
`validate_split`의 `sha256(source/meta/info.json)` 확인 시점을 근거로 삼은 것도 코드와 맞다.

내 4차 재계산과 같은 값이다. S′ 스텝 7,502도 같다.

`:600-610` 부근의 자기비판(잡음 바닥이 한 번 추출한 확률변수, 실효 표본 에피소드 12,
